# 阶段 9：环境对齐 SFT 与配对评测修复

日期：2026-08-13

## 阶段目标

修复权衡任务持续退化的问题，查明 SFT 是否真正学到了线上 Agent Loop/TRL 环境中的动作契约；同时审计 checkpoint 晋升评测是否真的实现了可比较的逐样本配对。

## 一、保守 GRPO 与旧格式修复均被拒绝

首个 4 步 GRPO 被拒绝后，运行了仅含 2 个权衡任务、1 步、`learning_rate=1e-7`、`beta=0.1` 的保守实验：

- 产物：`artifacts/grpo-qwen25-3b-tradeoff-step1-lr1e7`；
- 固定集整体成功率：84.375%；
- 权衡成功率：37.5%；
- 澄清、搜索、恢复能力保持 100%；
- 因总体和权衡能力仍退化，被晋升门拒绝。

随后构建 602 条旧格式权衡修复数据并运行 5 步 SFT。第一次训练发现 `max_train_examples=160` 直接截取排序后的前缀，导致 160 条全部是 replay，目标权衡样本实际没有进入训练。

该问题通过按最终动作轮询的确定性分层抽样修复，并增加单测。修复后子集为：

- `propose_tradeoff`：67；
- `search_pois`：67；
- `ask_user`：26。

重新训练后固定评测仍为 84.375%，权衡 37.5%，因此继续拒绝。这证明单纯增加看似正确的动作样本不能解决问题。

## 二、定位 SFT 与真实 RL 环境的分布偏差

对基线和候选模型的原始生成进行抓取后确认：失败 rollout 并非超长，也不是 JSON 损坏，而是模型生成了 `capability_check`。根因为旧 SFT 样本与真实 GRPO 环境不一致：

- 旧样本在权衡阶段提供 4 个工具：`capability_check / ask_user / propose_tradeoff / abort`；
- 实际 GRPO 权衡环境只开放 `propose_tradeoff / abort`；
- 旧样本用户消息是裸 `policy_state`，GRPO `reset` 返回的是带 `policy_state` 外层的结构。

这说明模型学到的不是错误业务逻辑，而是旧训练分布中的工具集合；评测时该工具不在允许范围内，因此被记为无有效动作。

## 三、构建与生产环境逐字同构的数据

新增 `scripts/build_aligned_tradeoff_repair_dataset.py`。构建器直接调用生产 TRL 环境的 `reset` 和路由工具契约生成样本，不再手工模拟提示。

数据约束：

- 只读取官方 GRPO train，不读取官方 validation；
- 数据版本：`sft-aligned-tradeoff-repair-96e8ce6853d16131`；
- 总计 758 条，train/validation/internal-test 为 530/114/114；
- 权衡目标 379 条，能力保持 replay 379 条；
- 训练子集 160 条：权衡 66、搜索 65、澄清 29；
- 不同内部 split 的 scenario id 无交集；
- 新增环境对齐、稳定分片和动作契约单测。

基于 `sft-qwen25-3b-multiturn-repair10` 运行 5 步 QLoRA SFT：

- 产物：`artifacts/sft-qwen25-3b-aligned-tradeoff-repair5`；
- train loss：0.5432；
- eval loss：约 0.41；
- 训练耗时：约 11.2 秒。

## 四、发现并修复伪配对随机评测

旧评测虽然两边使用相同全局 seed，但只在模型加载时设 seed。任一模型在前序题生成 token 数不同，都会改变之后所有题的随机数流，所以旧报告并非真正的逐样本配对。

现已增加 `sha256-task-sample-v1` 协议：以基础 seed、task id 和 sample index 生成独立 rollout seed。每道题、每个样本在不同 checkpoint 间使用相同采样随机流。

同时：

- 晋升门校验 `seed_protocol`，禁止新旧随机协议混比；
- 新增 `family_offset`，可以跳过已用题目构造后续扩大集；
- 晋升门校验 `family_offset`，禁止不同题目窗口混比；
- 新增稳定 seed、offset 选择和晋升契约单测。

## 五、环境对齐 SFT 通过两级晋升门

第一层为 8 道固定题、32 次 NF4 rollout：

- 基线整体成功率：81.25%；
- 候选整体成功率：90.625%；
- 平均 Reward：0.59316 → 0.77152；
- 澄清：75% → 100%；
- 恢复：100% → 100%；
- 搜索：100% → 100%；
- 权衡：50% → 62.5%。

第二层跳过上述题目，在后续 32 道 validation 题上运行 128 次配对 rollout：

- 整体成功率：78.90625% → 80.46875%；
- 平均 Reward：0.56659 → 0.59337；
- 澄清：87.5% → 87.5%；
- 恢复：87.5% → 93.75%；
- 搜索：87.5% → 84.375%；
- 权衡：53.125% → 56.25%；
- 搜索波动为 -3.125 个百分点，低于 5% 家族退化上限；
- 两级自动晋升门均通过。

因此 `sft-qwen25-3b-aligned-tradeoff-repair5` 取代旧基线，成为下一轮 GRPO 的合格起点。以上仍是受控验证集上的工程结论，不冒充大规模正式模型效果结论。
