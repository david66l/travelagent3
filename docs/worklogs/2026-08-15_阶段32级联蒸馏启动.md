- `train_dpo.py` 新增 `install_frozen_sft_reference_adapter`；
- 加载同一 SFT checkpoint 为只读 `ref` adapter；
- 恢复原 active adapter，优化器只训练 policy adapter；
- 单元测试验证 reference 安装和 active adapter 恢复。

修正版 checkpoint：`qwen3-1.7b-stage32-dpo-sftref-formal-v2`。训练报告明确记录 `reference_policy=frozen-sft-adapter:ref`。旧 DPO 为 104/150 且有 37 次流中断；修正版为 137/150、0 HTTP 错误。相对 SFT 的 +2/150，McNemar p=0.5，因此进入 Shadow，不直接替换 SFT 生产默认。
