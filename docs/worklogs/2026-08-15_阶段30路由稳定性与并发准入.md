# 阶段 30：路由稳定性与并发准入

日期：2026-08-15  
状态：完成；通过 Shadow 准入门

## 目标

验证 Stage29 的 4B+8B 路由结果是否可重复，并测量单张 RTX 4090 上不同并发下的延迟、吞吐、错误率和显存释放情况。

## 冻结路由

- 输入：Stage29 冻结的 150 条外部模型评测题。
- Stage28 DPO 4B 路径：81 条。
- Qwen3-8B 路径：69 条。
- 路由只读取 policy-visible state：`capability.status`、工具失败是否可恢复及剩余重试预算。
- 路由不读取 expected action 或模型输出。

## 多轮稳定性

### Temperature 0

- 完整重复 5 轮，共 750 次路由推理。
- 每轮均为 143/150，正确率 95.33%。
- 正确率波动 0.00 个百分点。
- 150/150 题的动作签名在五轮中完全一致。
- HTTP 错误 0。
- 每轮 False Abort 1/120，比例 0.83%。

### Temperature 0.2

- 完整重复 3 轮，共 450 次路由推理。
- 三轮分别为 144/150、143/150、142/150。
- 正确率范围 94.67%～96.00%，波动 1.33 个百分点。
- 动作稳定率 98.67%，两条题出现动作波动。
- HTTP 错误 0。
- 每轮 False Abort 1/120，比例 0.83%。

## GPU

- 4B vLLM 空载：22125 MiB。
- 8B vLLM 空载：22119 MiB。
- 套件结束：1 MiB。

vLLM 使用 `gpu-memory-utilization=0.90` 预分配 KV Cache，因此空载显存接近 22 GB，不能直接解释为模型权重大小。最终 GPU 已正常释放。

## 准入结论

以下门全部通过：

- 确定性最低正确率至少 94%。
