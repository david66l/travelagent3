# 决策边界困难集扩评与必要终止瓶颈

## 本轮目标

补齐上一轮搜索/恢复困难集未覆盖的澄清、取舍、终止和工具文本注入
场景，并验证当前最佳 SFT v2 是否同时提升了这些 Agent 决策能力。

## 完成内容

1. 新增 32 题冻结留出集，覆盖 4 类困难场景，每类 8 题；
2. 新增语义审计器，不再只按动作格式判分；
3. 使用原 SFT 与 SFT v2 `lr=8e-6`，在 seed 211、977 下各采样
   256 条完整轨迹，共完成 512 条；
4. 保留真实 `policy_driven` Agent Loop，完整规划题每条 9 次模型决策；
5. 发现并修复语义审计器对“多少天 / 多长时间”等自然表达的漏判，
   新增同义问法参数化回归测试；
6. 完成云端单测、编译、UTF-8 检查和本地 Ruff 检查；
7. 将原始 JSONL、报告、日志、数据集与评测脚本归档回本地。

## 结果

| 模型 | seed 211 | seed 977 | 合计 |
|---|---:|---:|---:|
| 原 SFT | 101/128 | 99/128 | 200/256（78.13%） |
| SFT v2 `8e-6` | 101/128 | 98/128 | 199/256（77.73%） |

两个模型均在澄清、可执行取舍和工具文本注入场景达到 64/64。必要
终止是唯一重大瓶颈：原 SFT 仅 8/64，候选仅 7/64。候选没有把
上一轮搜索/恢复能力的提升迁移到该决策边界。

配对结果为：两者都成功 198、都失败 55、仅基线成功 2、仅候选
成功 1，McNemar 精确双侧 `p=1.0`。因此不能宣称候选有提升。

## 判断与下一步

当前错误属于“模型还没学会规则”，不是“已经会但偶尔偏好错误”。
下一轮先补成对反事实 SFT 数据，把有替代方案与无替代方案做成只改
一个关键事实的训练对；在独立留出集复测达标后，再根据剩余错误决定
是否构造 DPO 偏好对。现在直接做 GRPO 的正例密度太低，训练效率差。
