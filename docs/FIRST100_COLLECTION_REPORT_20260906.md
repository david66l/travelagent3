# TravelAgent2 首批 100 个候选任务采集与审计

日期：2026-09-06。有效版本：travel-curriculum100.v2；Harness：evidence-progress-retry-v9。

第一批已完成云端场景构建、无模型预检、100 条学生首次轨迹采集及 7 条教师代表任务补采。这里是后训练数据试产，不代表正式规模或生产验收完成。未启动新训练，后两批 200 条尚未生成。

## 有效版本结果

| 类别 | 任务实例 | 学生通过现有任务判据 | 学生动作级候选 |
|---|---:|---:|---:|
| 正常规划 | 40 | 40 | 27 |

- 100 个实例来自 **20 个模板组，每组 5 个相关城市/日期变体**，共同使用一套固定场馆类型目录；不等于 100 个独立结构组。全部标记 train，未混入 dev/test。
- 教师在 7 个代表任务上，7/7 通过任务判据，4/7 通过动作级候选筛选。教师从任务初态重新示范，不是学生失败状态续跑，也不是训练后的提升。
- 两种来源合并覆盖 75 个候选任务、18 个模板组；教师额外补充 3 个候选任务。重复任务与轨迹不重复算独立任务。
- 学生保留 389 个动作审核候选，教师保留 30 个动作审核候选。**尚未导出正式 SFT 标签，训练就绪动作仍为 0**；候选数不能直接当作合格训练条数。

## 速度与审计

- 学生共享一个 Qwen3-4B + 首轮 SFT adapter，动态批量大小 4、任务并发 4；有效版本净采集 13.64 分钟，模型加载 23.55 秒，峰值 GPU 分配 11.53 GiB。
- 616 次学生策略请求、161 次 GPU generate 批次、605 个执行状态快照；616 次实际模型输入 token 哈希复核一致，0 次无完整生成哈希单列保留。
- 1 次原始格式/参数错误。未执行提案单列：{'raw_policy_error': 1, 'rejected_no_progress_proposal': 10}。不能把未执行提案从成本分母中删除。
- 30 个故障全部触发；成功恢复按实际终态另计。环境预检 100/100，相关回归 81 项通过，费用预留/恢复/并发控制 6 项通过。断点续跑验证没有重复加载模型或重复推理。
- 复核原始目录约束、轨迹重放、工具/求解器预算、状态哈希、原始策略动作、模型可见上下文与隐藏标签隔离。控制器补入的终止文案/备选项未替代原始模型动作。教师审核候选不含私有 reasoning_content。

## 已发现并处理的问题

第一次诊断的 POI ID 和来源 URL 带有私有场景标签，存在答案线索泄漏。student-v1、teacher-v1 及其候选已整体隔离，仅作工程诊断保留，0 条用于正式训练。修复为不透明 ID 后，重新预检、重新采集学生和教师；没有对旧输出替换 ID 后冒充新轨迹。下述费用包含隔离数据的开销。

模型侧主要缺口：证据过期/错实体后的无进展重复，以及检索范围过宽导致偏好匹配不足。教师也可能低偏好或失败，并未按模型名称直接放行。

当前规划仍使用通用午晚餐占位，具名餐厅路线完成数为 0。因此“现有任务判据通过”只覆盖当前 Harness 的执行、证据和硬约束检查，**不代表完整旅行产品质量通过**。此外，意图槽位预先从需求填写，未测意图解析；澄清在提出问题后结束，尚未覆盖用户回复后的完整会话。这些限制使本批保持动作级候选状态。

## 教师费用与总预算

价格依据为用户 2026-09-06 提供的控制台截图：活动输入 0.4、输出 1.4、缓存命中 0.115 元/百万 token；原价输入 0.8、输出 2.8。账本统一按原价、不使用缓存折扣估算，输入按 1,048,576 token 上界、输出按请求上限先预留，再用返回 usage 结算。

- 三批共 300 个任务共享 **100 元** API 额度，失败、隔离采集和重试全部累加；现有云算力另计，没有新增租机。
- 本程序累计 127 次 API 请求，保守已计提 **1.448934 元**，剩余额度 **98.551066 元**。
- 有效教师版本 62 次请求，已知输入 152033、输出 62097 token。程序累计 1 次用量未知请求，保留最大预留额；当前未结算请求为 0。
- 金额是按 token 和保守预留得到的估算，不是账户最终账单。账本在云端落盘并加锁，重启不退还未知请求费用；预算耗尽拒绝发送下一次请求。
