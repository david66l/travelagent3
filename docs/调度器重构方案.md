# 新调度器设计：约束内嵌 + 去掉校验修复

## 核心思想

**调度器直接产出合法行程，不需要事后校验修复。**

```
旧: 调度(尽力) → 校验(抓错) → 修复(打补丁) → 输出
新: 调度(带约束) → 轻量sanity check → 输出
```

## 🔴 4. assign_days_constrained()

替代旧的 `_assign_days`。每次决定是否将 POI 放入某天时，**同时检查 4 个约束**：

```python
def assign_days_constrained(pois, groups, travel_days, profile, must_see):
    """
    约束感知分日分配。
    每个 POI 分配前检查：预算/时间/must_see/多样性
    """
    days = [[] for _ in range(travel_days)]
    day_budget = [profile.budget_range or float('inf')] * travel_days
    day_minutes = [DAY_AVAILABLE_MINUTES] * travel_days
    day_categories = [set() for _ in range(travel_days)]

    # 1. Must-see first（保证不会丢）
    for poi_name in must_see:
        poi = find_poi(poi_name)
        best_day = min(range(travel_days), key=lambda i: day_minutes[i])
        days[best_day].append(poi)
        day_minutes[best_day] -= poi.duration + TRANSIT_ESTIMATE
        day_budget[best_day] -= (poi.cost or 0)
        day_categories[best_day].add(poi.category)

    # 2. Remote POIs to empty days
    ... (keep existing logic)

    # 3. Remaining POIs — constraint check for EACH assignment
    for poi in sorted_by_score:
        for day_idx in range(travel_days):
            if not _can_assign(poi, days[day_idx], day_budget[day_idx],
                               day_minutes[day_idx], day_categories[day_idx]):
                continue
            days[day_idx].append(poi)
            day_budget[day_idx] -= (poi.cost or 0)
            day_minutes[day_idx] -= poi.duration + TRANSIT_ESTIMATE
            day_categories[day_idx].add(poi.category)
            break

    return days

def _can_assign(poi, day, budget, minutes, categories):
    if poi.cost and budget - poi.cost < 0:
        return False  # 超预算
    if minutes - poi.duration < 60:
        return False  # 时间不够（至少留1h buffer）
    if poi.category in categories and len([p for p in day if p.category==poi.category]) >= 2:
        return False  # 同category不超过2个
    return True
```

```python
def total_transit_time(route):
    total = 0
    for i in range(len(route)-1):
        dist = distance_km(route[i].location, route[i+1].location)
        transit = dist / 50 * 60  # minutes at 50km/h
        total += transit
    return total
```

## 🔴 6. assign_time_slots()

替代旧的 `_build_day_plans` 中的时间分配逻辑。**验证营业时间**：

```python
def assign_time_slots(day_pois, day_idx):
    current = DAY_START
    activities = []

    for i, poi in enumerate(day_pois):
        # Transit time
        if i > 0:
            dist = distance_km(day_pois[i-1].location, poi.location)
            current += int(dist / 50 * 60)

        # Opening hours check
        if poi.open_time and current < poi.open_time_minutes:
            current = poi.open_time_minutes  # wait until open
        if poi.close_time and current + poi.duration > poi.close_time_minutes:
            # Soft warning — schedule anyway but note it
            logger.warning(f"{poi.name} ends after closing time")

        # Meal insertion
        current = _maybe_insert_meal(current, activities, day_idx)

        activities.append(Activity(
            poi_name=poi.name,
            start_time=minutes_to_time(current),
            end_time=minutes_to_time(current + poi.duration),
            ...
        ))
        current += poi.duration + 15  # buffer, not fixed 30min

    return activities
```

## 🟡 9. sanity_check()

轻量检查，只记录不修复：

```python
def sanity_check(schedule, profile):
    warnings = []
    for day in schedule:
        if not day.activities:
            warnings.append(f"Day {day.day_number} has no activities")
        if day.total_cost > (profile.budget_range or float('inf')):
            warnings.append(f"Day {day.day_number} over budget")
    return warnings  # never blocks output
```
