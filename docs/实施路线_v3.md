## P0a: 规划引擎 → OR-Tools CP-SAT

**理由**: 主人要求一步到位。OR-Tools 是 Google 的生产级约束求解器，支持：
- 多约束同时满足（时间/预算/体力/人群）
- 多目标加权优化（偏好 × 0.6 + 路线 × 0.3 + 均衡 × 0.1）
- 失败时给出「最近可行解」而非直接报错

**改动文件**:
- 新增 `backend/src/planner/core/or_scheduler.py`
- 保留现有 `daily_scheduler.py` 作为 fallback
- `planning_pipeline.py` 中切换调用

```python
# or_scheduler.py 核心接口
def solve_itinerary_or(
    pois: list[ScoredPOI],
    profile: UserProfile,
    must_see: list[str],
) -> list[DayPlan]:
    """
    OR-Tools CP-SAT 求解行程。
    
    变量: X[p][d][s] = 1 表示 POI p 安排在 Day d 的 Slot s
    约束:
      1. 每 POI 最多一次
      2. 每天总时长 ≤ DAY_AVAILABLE
      3. 总预算 ≤ profile.budget_range
      4. must_see 必须包含
      5. 同 category 每天 ≤ 2
      6. 体力约束: 日步行 ≤ profile.max_walk
    目标:
      MAX( 偏好分 × 0.6 - 车程 × 0.3 - 日方差 × 0.1 )
    """
```

## P0b: LangGraph 迁移

**理由**: 主人要求现在做。LangGraph StateGraph 天然支持：
- 循环流程（追问→再识别→规划）
- 分支决策（意图不同走不同路径）
- 断点持久化（用户中断后可续）
- 人机协作（关键节点暂停等确认）

**架构**:

```python
# backend/src/agent/graph.py

from langgraph.graph import StateGraph, END
from langgraph.checkpoint.postgres import PostgresSaver

# 全局状态
class TravelAgentState(TypedDict):
    messages: list[dict]
    slots: dict          # 槽位
    intent: str
    profile: dict        # 用户画像
    knowledge: list[str] # RAG 检索结果
    plan: list[dict]     # 行程
    tools_called: list
    next_action: str

# 节点
def understand_node(state): ...   # 意图理解 + 槽位抽取
def profile_node(state): ...      # 加载用户画像
def knowledge_node(state): ...    # RAG 检索
def planner_node(state): ...      # OR-Tools 规划
def tools_node(state): ...        # 工具调用
def output_node(state): ...       # 格式化输出

# 图
builder = StateGraph(TravelAgentState)
builder.add_node("understand", understand_node)
builder.add_node("profile", profile_node)
builder.add_node("knowledge", knowledge_node)
builder.add_node("planner", planner_node)
builder.add_node("tools", tools_node)
builder.add_node("output", output_node)

builder.set_entry_point("understand")

# 条件边
builder.add_conditional_edges("understand", route_after_understand, {
    "clarify": "output",     # 信息不足→追问用户
    "plan": "profile",       # 信息齐全→加载画像
    "query": "knowledge",    # 查询信息→直接回答
})

builder.add_edge("profile", "knowledge")
builder.add_edge("knowledge", "planner")

builder.add_conditional_edges("planner", route_after_plan, {
    "need_tools": "tools",   # 需要查实时数据
    "done": "output",        # 规划完成
})

builder.add_edge("tools", "planner")  # 工具结果→回到规划

# 持久化
checkpointer = PostgresSaver.from_conn_string(settings.database_url)
graph = builder.compile(checkpointer=checkpointer)
```

## P1: 知识库 (pgvector + bge-large-zh)

### Embedding 选型: bge-large-zh-v1.5

| 指标 | bge-large-zh-v1.5 |
|---|---|
| 维度 | 1024 |
| MTEB中文排名 | #1 (开源) |
| 推理速度 | ~20ms/条 (CPU) |
| 开源协议 | MIT |

### pgvector 表结构

```sql
CREATE EXTENSION vector;

CREATE TABLE knowledge_embeddings (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    city VARCHAR(50),
    content TEXT,
    content_type VARCHAR(20),   -- 'guide' | 'tip' | 'restaurant' | 'attraction'
    embedding vector(1024),
    metadata JSONB,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX ON knowledge_embeddings 
USING ivfflat (embedding vector_cosine_ops) WITH (lists = 100);
```

### 检索接口

```python
async def search_knowledge(query: str, city: str = None, top_k: int = 5):
    embedding = await bge.encode(query)  # 1024维
    
    results = await db.fetch(
        """
        SELECT content, content_type, metadata,
               1 - (embedding <=> $1) AS similarity
        FROM knowledge_embeddings
        WHERE ($2::text IS NULL OR city = $2)
        ORDER BY embedding <=> $1
        LIMIT $3
        """,
        embedding, city, top_k
    )
    return results
```

async def update_user_profile(user_id, trip_feedback):
    # 1. 从反馈中提取偏好变化
    new_prefs = extract_preferences(trip_feedback)
    
    # 2. 结构化字段直接更新
    await db.execute(
        "UPDATE user_profiles_vector SET profile_json = $1 WHERE user_id = $2",
        merge_profile(old, new_prefs), user_id
    )
    
    # 3. 向量加权更新 (0.7×旧 + 0.3×新)
    old_embedding = await get_embedding(user_id)
    new_embedding = await bge.encode(summarize(new_prefs))
